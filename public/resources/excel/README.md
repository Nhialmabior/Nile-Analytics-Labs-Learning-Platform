# Excel Practice Dataset

This is a **synthetic teaching dataset** created for the Nile Analytics Labs Excel for Data Analysis course.

## What's included

- 50 fictional learner records.
- School, county, gender, age and grade fields.
- Attendance, assessment and programme-status indicators.
- Household income values in Kenyan shillings (KES).

## Designed learning activities

The file intentionally contains a small number of data-quality issues, including blank values. Learners should also practise checking for duplicates, validating values and documenting cleaning decisions before analysis.

## Important

All records are fictional and do not describe real learners or households. Do not treat the figures as research findings or representative statistics.

## Suggested exercises

1. Format the records as an Excel table.
2. Identify blank cells and duplicate records.
3. Calculate attendance rates and average assessment scores.
4. Compare results by school, gender and grade.
5. Build a PivotTable and a one-page dashboard.
